# VelocityProfile::Core

Core 是单轴速度曲线的公共接口包，包标识为 `VelocityProfile::Core`；当前 `cpkg.toml` 没有声明其他包依赖。它不选择规划算法，也不控制电机或维护控制循环。

## 接口使用边界

通过 [`IVelocityProfile.hpp`](IVelocityProfile.hpp) 中的 `velocity_profile::IVelocityProfile` 抽象，消费方可以检查规划是否成功、取得运动总时长，并按相同的轨迹时间采样位置、速度和加速度。具体规划器负责求解边界状态、约束与可行性；接口基类的 `success()` 默认返回 `false`，自定义规划器须提供自身的成功状态语义。

时间参数表示曲线内的时间，而非硬件绝对时间戳；调用方负责把调度时钟映射到轨迹时间。基类不统一规定越界采样、失败后的采样值或具体可行性条件，应遵循所用实现的契约。函数签名以头文件为准，不在本文建立逐函数 API 副本。

## 单位与消费方职责

接口使用 `float`，不附带单位或自动换算。调用方须选择一致的位置单位 $U$ 和时间单位 $\tau$，相应速度为 $U/\tau$，加速度为 $U/\tau^2$；具体算法若接受加加速度，则为 $U/\tau^3$。例如直线位移与转角可分别采用各自一致的单位，不能把它们或不同时间基准直接混用。

消费方负责控制周期、执行器约束和跟踪闭环。连续曲线可采样不等于离散系统能够准确跟踪；接入时应检查控制周期、饱和及量纲换算。
